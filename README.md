# Site Márcia Carvalho

Site institucional desenvolvido para Márcia Carvalho, Psicóloga e Neuropsicóloga.

O projeto apresenta informações sobre sua atuação profissional, serviços oferecidos e formas de contato, com foco em uma experiência visual limpa, profissional e responsiva.

## Sobre o projeto

O site foi desenvolvido com HTML5 e CSS3, com uma estrutura simples e organizada, priorizando:

- Identidade visual profissional
- Layout responsivo
- Navegação entre páginas
- Apresentação dos serviços
- Informações profissionais
- Links de contato e redes sociais

## Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts
  - Lato
  - Cormorant Garamond
- Git
- GitHub

## Páginas

### Início

Apresentação profissional e acesso às principais áreas de atuação.

### Sobre mim

Apresentação da profissional, formação e abordagem clínica.

### Serviços

Apresentação dos serviços oferecidos:

- Psicoterapia
- Avaliação Neuropsicológica

### Psicoterapia

Informações sobre o acompanhamento psicológico.

### Avaliação Neuropsicológica

Página destinada à apresentação do serviço de avaliação neuropsicológica.

### Contato

Canais de contato e redes sociais.

## Objetivo

O projeto foi desenvolvido para criar uma presença digital profissional, com uma interface moderna, clara e acessível para apresentação dos serviços e informações profissionais.
